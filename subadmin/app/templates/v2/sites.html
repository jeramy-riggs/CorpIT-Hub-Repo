How DNS and certificates work here

DNS is written to all three domain controllers (adcoredc16009, adcohidc16009, dcw13sna01us). A zone backup is taken first, and a name that already points somewhere else is never changed. "Pending" means the first controller has it and the others are catching up — push again in a few minutes.

Certificates come from NRPI-PKI04AWSW2US-CA. The console makes the request file when a site is created; you take it to http://pki04awsw2us.nrpi.local/certsrv/ and upload the answer. Before installing, the console confirms the certificate matches the site's key, then checks nginx is really serving it.

One host must never go behind the sign-in: directory.{{ base_domain }}. Phones and Macs talk to it with a plain password and cannot follow a login redirect.
