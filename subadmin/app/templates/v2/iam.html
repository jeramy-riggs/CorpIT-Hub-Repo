Why only these groups show up

Sign-in only looks at a person's SaaS-ITH-* role and approver groups. {% if denied_groups %}{{ denied_groups|join(', ')|safe }} {{ 'is' if denied_groups|length == 1 else 'are' }} not offered because {{ 'it has' if denied_groups|length == 1 else 'they have' }} no console role, so a grant could never take effect. {% endif %}To add a group: create a SaaS-ITH- group in Active Directory and give it a role — it then appears here.

Two things are fixed on purpose: the platform owner always has every permission, and Change these permissions stays owner-only. Together they mean nobody can lock every administrator out.
