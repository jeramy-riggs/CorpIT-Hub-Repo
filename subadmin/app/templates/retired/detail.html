Deploy NRPI-CA certificate

Upload the file the CA returned after signing this subdomain's CSR — the .p7b (certificate chain) is best; a .cer/.pem leaf also works. Before anything changes, the server checks the cert matches this subdomain's private key and names {{ s['fqdn'] }}; then it installs the ordered full chain, reloads nginx, and confirms the new certificate is actually being served. The previous cert and vhost are backed up automatically.
